IP → 节点测速筛选（WebUI）

粘贴 FOFA → 去重提取 IP:端口 → 并发测速剔除 timeout → 探测落地 IP → 输出结果。

1) 粘贴 FOFA 文本

会自动提取并去重所有 IP:端口。

2) 配置（config.json）

提示：并发/重试也可在下面临时覆盖（不会自动写回配置）。

2.1) 节点订阅规则（可视化编辑：nodeTemplate）

这里改动会同步写入 `config.json` 的 `nodeTemplate`。如果你需要更高级的规则，仍可直接编辑上面的 JSON。

2.2) 自定义测地区 API（可选，一行一个 Base URL）

写入 `geoApi.customBaseUrls`，将优先于内置列表轮询；留空则仅用配置/内置 API。支持：ip-api.com、ipwho.is、ipapi.co、ipwhois.app、ipapi.is（程序内置已含多条兜底）。

3) 测试参数（临时覆盖）

失败原因会分类统计（timeout/auth/network/invalid_response/…）。
